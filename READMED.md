# Taller VECM / VAR - Econometría II

Este repositorio contiene los scripts y resultados para el taller de modelos VAR/VECM. Incluye la generación automática de informes en HTML y archivos Excel.

## 🚀 Cómo clonar y ejecutar este proyecto

Sigue estos pasos para replicar el proyecto en tu computadora:

### 1. Requisitos previos
Asegúrate de tener instalado:
- [Git](https://git-scm.com/downloads)
- [Anaconda o Miniconda](https://docs.conda.io/en/latest/miniconda.html)

### 2. Clonar el repositorio
Abre tu terminal y ejecuta:
```bash
git clone https://github.com/TU_USUARIO/TU_REPOSITORIO.git
cd TU_REPOSITORIO
